# Initial D — Omarchy theme

AE86 panda black/white, Mt. Akina night navy, tail-light red, Eurobeat yellow.

Install:
    cp -r omarchy-initial-d-theme ~/.config/omarchy/themes/initial-d
    omarchy-theme-set initial-d

Backgrounds: drop wallpapers (Akina downhill, Hachi-Roku, Fujiwara Tofu Shop) into `backgrounds/`.
